# Dance Studio Pro · 舞者全能工作台使用指南

Dance Studio Pro 是一款专为舞者与扒舞练习打造的本地工作台。**所有视频文件与打点配置均安全缓存在你的本地浏览器（IndexedDB）中**，无需上传服务器，不消耗流量，断网亦可随时练习。

---

## 一、 项目大厅与多素材管理

1. **创建扒舞项目**：
   * 点击右上角 **「+ 新建扒舞项目（支持多选视频）」**，可一次性导入多个关联视频（例如：正面教学版、背面练习室版、慢动作分解版）。
2. **项目内切换视频**：
   * 进入工作台后，顶部素材栏可随时切换当前项目下的不同视频，每个视频的循环段落、镜面区间和语速设置均独立保存。
   * 随时可通过右上角 **「+ 添加视频到此项目」** 补充新视频。

---

## 二、 播放器与高精度时间轴控制

* **播放 / 暂停**：点击视频画面、点击左下角「播放/暂停」按钮，或按键盘 **`Space`（空格键）**。
* **画面局部放大**：将鼠标悬停在视频画面上，滚动**鼠标滚轮**即可无级缩放（50% ~ 400%），方便看清脚下步法细节；点击右上角「重置大小」恢复 100%。
* **原视频秒数时间轴**：播放器底部进度条始终保持**从左到右**推进（不会因镜面翻转而左右颠倒），并实时显示精确到 `0.01s` 的原视频时间位置。

## 三、 核心功能一：段落循环与变速

在工作台切换到 **「段落循环与变速」** 标签页：

### 1. 创建与微调循环段落
* **波形框选**：在下方音频波形图上按住鼠标左键拖动，即可快速创建新的循环段落（默认命名 `段落 1`、`段落 2`…）。
* **实时画面预览**：在列表中点击任意段落，或在波形图上拖动段落的左右边缘、修改起止秒数输入框时，视频画面会自动定格跳转到对应帧进行预览。
* **独立调速与重复次数**：每个段落可单独设置专属播放速度（`0.25x ~ 1.50x`）与重复遍数。勾选「所有循环段跟随此基准速度」可统一覆盖为全局速度。

### 2. 四种播放与循环模式
| 模式名称 | 适用场景与行为说明 |
| :--- | :--- |
| **1. 单段落循环** | 锁定当前选中的段落无限循环播放，适合死磕单个难点动作。 |
| **2. 多段落循环** | 仅在已标记的多个段落之间循环跳转（跳过非标记片段）。支持「按设定次数顺序循环」或「合并为完整视频连贯循环（各1遍）」。 |
| **3. 练习模式** | 播放整支舞蹈，遇到标记的段落时自动降速并重复指定遍数，练完后自动恢复原速继续往下跳。 |
| **4. 关闭分段循环** | 忽略所有分段标记，按基准速度流畅通跳全曲（可配合右上角「全曲循环：开/关」使用）。 |

## 四、 核心功能二：正 / 镜面区间设置

针对舞蹈视频中镜头经常在**正面机位**和**背面机位**之间切换的情况，切换到 **「正 / 镜面区间设置」** 标签页：

1. **按镜面区间自动切换（推荐）**：
   * 在音频波形图上框选镜头切换为正面的时间段，或点击 **「+ 在当前秒数添加翻转区间」**。
   * 播放到该区间时，画面会自动执行丝滑水平镜面翻转（左上角提示「正面镜面 (已翻转)」）；离开该区间后自动恢复正常背面视角。
   * 点击区间右侧的状态按钮，可随时将该区间切换为「状态：镜面 (已翻转)」或「状态：非镜面 (未翻转)」。
2. **全局一键覆盖**：
   * 顶部提供 **「全片镜面」** 与 **「全片非镜面」** 按钮，可一键覆盖所有区间设置。

---

## 五、 常用快捷键一览

* **`Space`（空格）**：播放 / 暂停
* **`A` 键**：将当前播放秒数设为选中循环段的**起点**
* **`B` 键**：将当前播放秒数设为选中循环段的**终点**
* **`[` 或 `-` 键**：降低播放速度（`-0.05x`）
* **`]` 或 `=` 键**：提高播放速度（`+0.05x`）
